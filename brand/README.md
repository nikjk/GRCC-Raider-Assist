# Official GRCC brand assets

Colors are #00306B (PMS 294) and #FFDD00 (PMS 116).

The desktop uses a **generic letter R program icon**, not an imitation of the official Raiders mascot or GRCC logomark. Before college-wide distribution, obtain approved official logomark and mascot assets from GRCC Marketing & Communications and have the app icon/usage approved.
